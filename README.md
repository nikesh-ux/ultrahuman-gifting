# Ultrahuman Gifting prototype

Clickable prototype for the unified gifting flow: Gift Sizing Kits, Ring Vouchers and Gift Cards.

- `v2/index.html` is the full prototype. Open it in a browser.
- `v2/src.html` is the source. Run `python3 v2/build.py` to rebuild `index.html` and `artifact.html`.
- `v2/assets/` holds images and SVGs inlined by the build.
- `lp-variations.html` is the board of ten landing page wireframes.
